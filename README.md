## How to Use

1. Open `index.html` in your web browser
2. Navigate through the sections using the menu
3. Update the SoundCloud URL in the JavaScript section to change the featured track
4. Customize the contact form with your Formspree ID

## Customization

### Change Featured Track
Find this line in the JavaScript section of `index.html`:
```javascript
const soundcloudUrl = "https://soundcloud.com/thepapamoon/godless-papa-moon?si=...";
```
Replace with your desired SoundCloud track URL.

### Setup Contact Form
Replace `your-id-here` in the form action:
```html
<form action="https://formspree.io/f/your-id-here" method="POST">
```
